Job Search Agent

Search real job listings (via Jooble) and draft (never auto-send) a tailored application email for each.

← LinkedIn posting agent  |  Newsletter draft →

This does not scrape LinkedIn or Naukri Gulf (both prohibit that in their terms) — it uses the public Jooble job search API. Emails are drafted only, never sent automatically.

"Check email alerts" reads job-alert emails already in your own inbox (via IMAP) — it doesn't scrape LinkedIn or Naukri Gulf. You must first set up a saved-search alert on each site yourself and configure IMAP_EMAIL/IMAP_APP_PASSWORD in .env (see README.md).
